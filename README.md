# MurVeg
Android mobile app - Murmansk vegetation catalog
Приложение-справочник по растениям Мурманской области. Позволяет искать растения по названию и описанию, просматривать краткую информацию и фильтровать по типу растительности (деревья, кустарники, травы).
Приложение НЕ делает:
- Поиск растения по фото
- Экспорт и импорт данных пользователем
- Интеграцию с гис-системами
- Предоставляет информацию о животном мире,памятниках архитектуры и ином. Только растительность.

Команда: Юлия Логинова одна за всех-Product Owner, Scrum Master, Developers.

Характеристики:
- Язык: Kotlin.
- UI: Jetpack Compose. 
- Архитектура: MVVM с использованием ViewModel и Repository
- Локальное хранение: Room Database
- Минимальное покрытие тестами: 50% бизнес-логики
