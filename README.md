# MurVeg
Android mobile app - Murmansk vegetation catalog
Приложение-справочник по растениям Мурманской области. Позволяет искать растения по названию, просматривать краткую информацию и фильтровать по типу растительности (деревья, кустарники, травы).
Команда: Юлия Логинова.

Характеристики:
- Язык: Kotlin.
- UI: Jetpack Compose. 
- Архитектура: MVVM с использованием ViewModel и Repository
- Локальное хранение: Room Database
- Минимальное покрытие тестами: 50% бизнес-логики
- Приложение работает оффлайн, данные сохраняются локально
-Поддержка Android 7.0 (API 24) и выше.
-Интерфейс на русском языке.

Инструкция по запуску:
1. Клонировать репозиторий
git clone https://github.com/ollyulia/MurVeg.git
cd MurVeg
2. Открыть проект в Android Studio
Запустить Android Studio.
Открыть  папку MurVeg
Дождаться, пока Android Studio все обдумает.
3. Выбрать устройство для запуска
4. Запустить приложение
Дождаться сборки и установки APK.
На устройстве приложение запустится автоматически; далее его можно открывать как обычное.
Для запуска на реальном устройстве нужно включить режим разработчика и отладку (USB или по Wi‑Fi) на устройстве.

Требования к устройству:
– Android 7.0 (API 24) или выше;
– поддержка установки пользовательских приложений (отладка по USB или ADB по Wi‑Fi).

Описание архитектуры:
Приложение построено по архитектурному паттерну MVVM (Model–View–ViewModel) с использованием:
Kotlin
Jetpack Compose / Material 3 — декларативный UI
Navigation Compose — навигация между экранами
Пока in‑memory источник данных (заглушка вHomeViewModel), в дальнейшем планируется замена на  Room Database.

Архитектура разделена на три основных слоя:

View — пользовательский интерфейс — Composable‑экраны и компоненты:
Основные экраны:
HomeScreen — Главный экран каталога растений, 
Содержит:
поле поиска (SearchTopBar);
кнопку запуска поиска (стрелка);
кнопку перехода в избранное (иконка сердца);
выпадающий список фильтров (FilterDropdown) по типу растительности (Все/Деревья/Кустарники/Травы);
список растений.

FavoritesScreen — Экран избранных растений.
Содержит:
верхнюю панель поиска (SearchTopBar) со стрелкой «Назад»;
список избранных (FavoriteItemRow) с возможностью удалить элемент;
поиск по избранному.

PlantDetailsScreen — Экран детальной информации о растении.
Содержит:
верхнюю панель: стрелка «Назад», название растения, иконка избранного;
заглушку под изображение;
описание и условия произрастания;
кнопку «Похожие»;
горизонтальный список похожих растений по тегам (SimilarPlantsRow).

ViewModel — бизнес‑логика — HomeViewModel и HomeUiState HomeViewModel:
Загрузка данных (loadPlants()):
сейчас – инициализация списка растений из заглушки вinit {}в будущем здесь будет обращение к базе данных/репозиторию.
Поиск и фильтрация onSearchQueryChange():
— обновление поисковой строки с валидацией (ограничение длины, нормализация строки, ошибка при > 50 символов);
— сброс поиска;
— смена текущего фильтра;
— комбинированная фильтрация тпо типу и по поисковой строке(поиск в name/description/tags с нормализацией е/ё).)
Работа с избранным:
— переключение флага isFavorite у растения и обновление списков;
— получение списка избранных растений;
— поиск среди избранных по тем же правилам, что и глобальный поиск.
Детали растения:
— поиск растения по идентификатору для экрана деталей.
все изменения состояния автоматически обновляют UI‑экраны, подписанные на uiState.

Model - датакласс Plant.kt:
Plant —  модель растения:

id: Long — уникальный идентификатор;
name: String — название;
type: PlantType — тип (дерево/кустарник/трава);
description: String — краткое описание;
conditions: String — условия произрастания;
facts: String —  интересные факты;
imageResId: Int? — ссылка на ресурс изображения (для будущих свершений);
tags: List<String> — список тегов для поиска похожих растений;
isFavorite: Boolean — признак избранного.
